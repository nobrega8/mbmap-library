# ความเข้ากันได้

เครื่องมือที่อ่านไฟล์ `.mbmap` และส่วนของรูปแบบ ([SPEC.md](SPEC.md)) ที่แต่ละตัวรองรับ

| <img src="assets/tools/mtui.png" width="20" height="20" alt="" align="top"> [MTUI](https://github.com/inowattio/MTUI) | ไคลเอนต์ Modbus TCP/RTU สำหรับเทอร์มินัลที่ควบคุมด้วยคีย์บอร์ด สำหรับ Windows, Linux และ macOS พร้อมเดโมบนเว็บ (ตั้งแต่เวอร์ชัน 1.6.0) | นำเข้าแมปที่วาง แต่ละรีจิสเตอร์ถูกปักหมุดและติดป้ายด้วยชื่อและหน่วย และได้รับกฎที่ถอดรหัสชนิด ลำดับไบต์และเวิร์ด สเกล ออฟเซ็ต และตารางแปลค่า รีจิสเตอร์ที่ถอดรหัสไม่ได้ (สตริง ฟิลด์หลายบิต) จะเก็บเฉพาะป้าย |

## การเพิ่มเครื่องมือ

กำลังสร้างเครื่องมือที่อ่าน `.mbmap` ใช่ไหม ให้ทำตาม [SPEC.md](SPEC.md) และตรวจเทียบกับไฟล์ตัวอย่างใน [`tests/`](tests/) แต่ละไฟล์ระบุการวินิจฉัยที่ผู้อ่านต้องรายงาน จากนั้นเปิด pull request เพิ่มเครื่องมือของคุณลงในหน้านี้พร้อมสิ่งที่รองรับ การรองรับบางส่วนไม่เป็นไร ให้ระบุว่าอ่านส่วนใดและเมินส่วนใด
