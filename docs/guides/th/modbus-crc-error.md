# ข้อผิดพลาด CRC ของ Modbus บน RS-485

ข้อผิดพลาด CRC หมายความว่าเฟรมมาถึงแล้ว แต่เช็กซัมไม่ตรง ไบต์ถูกเปลี่ยนหรือหายระหว่างทาง ต่างจากที่อยู่ผิด มันชี้ไปที่ลิงก์ทางกายภาพหรือจังหวะเวลา

## สาเหตุที่พบบ่อย

- **สัญญาณรบกวน** สายไม่มีชีลด์ที่เดินข้างสายไฟกำลังหรืออินเวอร์เตอร์ ใช้สายคู่บิดเกลียวแบบมีชีลด์ โดยต่อชีลด์ลงกราวด์ที่ปลายด้านเดียวเท่านั้น
- **ไม่มีหรือมีเทอร์มิเนชันเกิน** ตัวต้านทาน 120 Ω หนึ่งตัวที่ปลายแต่ละด้านของบัส และไม่มีตรงกลาง
- **ไม่มีไบแอส** บัสที่ว่างอยู่และไม่มีตัวต้านทานไบแอสจะลอยตัว และไบต์แรก ๆ ของเฟรมอาจถูกอ่านผิด ตัวแปลงและมาสเตอร์หลายตัวมีตัวเลือกไบแอส
- **การแตกกิ่งและการเดินสายแบบดาว** RS-485 ต้องการสายเส้นเดียวจากอุปกรณ์หนึ่งไปอีกอุปกรณ์หนึ่ง ไม่ใช่การแตกกิ่ง
- **อัตราบอดคลาดเล็กน้อย** ในตัวแปลงราคาถูกหรือที่อัตราสูง ลองลดอัตราบอด
- **เฟรมรวมกัน** หากมาสเตอร์ส่งคำขอถัดไปก่อนที่บัสจะเงียบ 3.5 ช่วงตัวอักษร อุปกรณ์จะเห็นเป็นเฟรมยาวที่เสียหายเฟรมเดียว ให้เพิ่มหน่วงเวลาระหว่างคำขอ
- **มาสเตอร์สองตัว** หรืออุปกรณ์ที่ตอบที่ที่อยู่เดียวกับอุปกรณ์อื่น

## ขั้นตอน

1. ลดอัตราบอดแล้วดูว่าข้อผิดพลาดหยุดหรือไม่
2. ทดสอบด้วยอุปกรณ์หนึ่งตัวและสายสั้น หากใช้ได้ ปัญหาอยู่ที่บัส ไม่ใช่อุปกรณ์
3. ตรวจเทอร์มิเนชันขณะปิดไฟ ความต้านทานระหว่าง A กับ B ควรอยู่ที่ราว 60 Ω เมื่อติดตัวเทอร์มิเนเตอร์ทั้งสองตัว
4. เพิ่มไบแอสหากมาสเตอร์หรือตัวแปลงมีให้
5. เพิ่มช่วงเวลาการสอบถามและเวลาหมดเวลา

ข้อผิดพลาด CRC เป็นครั้งคราวบนบัสอุตสาหกรรมที่ยาวเป็นเรื่องปกติ เครื่องมือควรลองใหม่ แต่ข้อผิดพลาดกับเฟรมส่วนใหญ่ไม่ปกติ
