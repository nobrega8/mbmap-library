# Modbus unit ID (slave ID): อุปกรณ์ตัวไหนตอบ

ทุกคำขอ Modbus มี unit ID ขนาดหนึ่งไบต์ หรือเรียกว่า slave ID, ที่อยู่ slave หรือที่อยู่อุปกรณ์

## บน RS-485 (Modbus RTU)

- อุปกรณ์แต่ละตัวบนบัสมีที่อยู่ของตัวเอง 1 ถึง 247 ตั้งที่หน้าจอ ด้วย DIP สวิตช์ หรือในซอฟต์แวร์ตั้งค่า
- ที่อยู่ 0 คือบรอดแคสต์ อุปกรณ์ทุกตัวปฏิบัติตามคำสั่งเขียน และไม่มีตัวใดตอบ การอ่านไปที่ 0 ไม่ได้รับคำตอบ
- อุปกรณ์ที่ตั้งเป็นที่อยู่อื่นจะเมินคำขอของคุณโดยสิ้นเชิง unit ID ที่ผิดจึงดูเหมือนอุปกรณ์ตาย คุณจะได้[การหมดเวลา](modbus-timeout-no-response) ไม่ใช่ข้อผิดพลาด

## บน Modbus TCP

- อุปกรณ์ที่เข้าถึงโดยตรงด้วย IP มักเมิน unit ID หรือคาดหวัง 1 บางตัวคาดหวัง 0 หรือ 255 และไม่กี่ตัวปฏิเสธทุกค่าที่ไม่ใช่ค่าที่ตั้งไว้
- หลังเกตเวย์ TCP-เป็น-RTU unit ID เลือกอุปกรณ์ซีเรียล โดยต้องตรงกับที่อยู่ RS-485 ของอุปกรณ์นั้น ตัวเกตเวย์เองมักตอบที่ 0, 255 หรือ ID ที่ตั้งไว้
- อุปกรณ์บางรุ่นที่มีหลายส่วนภายใน (อินเวอร์เตอร์ที่มีมิเตอร์และแบตเตอรี่) ตอบ unit ID ที่ต่างกันสำหรับแต่ละส่วน

## การหาที่อยู่ที่ไม่ทราบ

- อ่านจากหน้าจอหรือป้ายของอุปกรณ์
- สแกน: ส่งคำขออ่านรีจิสเตอร์ทั่วไปไปยังทุกที่อยู่ตั้งแต่ 1 ถึง 247 ด้วยอัตราบอดของอุปกรณ์ แล้วจดว่าตัวใดตอบ ทำเช่นนี้เมื่อต่ออุปกรณ์ตัวนั้นเพียงตัวเดียว
- รีเซ็ตเป็นค่าจากโรงงาน คู่มือจะระบุค่าเริ่มต้น (มักเป็น 1)

## แมป MBMap บันทึกเรื่องนี้อย่างไร

แมประบุ `unit_id` เริ่มต้นของอุปกรณ์ (รวมถึงการตั้งค่าซีเรียลและพอร์ต TCP) ค่าเริ่มต้นเป็นเพียงจุดเริ่มต้น เพราะอุปกรณ์มักถูกตั้งค่าใหม่ตอนติดตั้ง
