# ลำดับไบต์และลำดับเวิร์ด: เมื่อค่า 32 บิตออกมาผิด

แรงดันอ่านได้ 1.7 × 10³⁸ มิเตอร์พลังงานกระโดดทีละ 65,536 หรืออุณหภูมิเป็นเลขลบเล็ก ๆ รีจิสเตอร์ถูกต้อง แต่ลำดับการนำสองรีจิสเตอร์ของค่า 32 บิตมาประกอบกันไม่ถูกต้อง

## หนึ่งรีจิสเตอร์ง่าย สองรีจิสเตอร์ไม่ง่าย

รีจิสเตอร์ Modbus มี 16 บิต ส่งไบต์ที่มีนัยสำคัญสูงสุดก่อน มาตรฐานไม่ได้กล่าวถึงค่าที่ยาวกว่าหนึ่งรีจิสเตอร์ ผู้ผลิตแต่ละรายจึงเลือกเองว่าจะแบ่งจำนวนเต็มหรือ float 32 บิตลงสองรีจิสเตอร์อย่างไร (และค่า 64 บิตลงสี่รีจิสเตอร์)

ทั้งสี่ลำดับมักตั้งชื่อตามไบต์ของค่า โดย `A` คือไบต์ที่มีนัยสำคัญสูงสุด:

| ชื่อ | รีจิสเตอร์ 1 | รีจิสเตอร์ 2 | ชื่ออื่น |
|---|---|---|---|
| `ABCD` | A B | C D | big-endian เวิร์ดสูงก่อน |
| `CDAB` | C D | A B | สลับเวิร์ด เวิร์ดต่ำก่อน LSW first |
| `BADC` | B A | D C | สลับไบต์ |
| `DCBA` | D C | B A | little-endian สลับทั้งคู่ |

`ABCD` และ `CDAB` ครอบคลุมอุปกรณ์เกือบทั้งหมด `CDAB` พบบ่อยใน Schneider, Carlo Gavazzi และมิเตอร์จีนหลายรุ่น ส่วน `ABCD` พบใน Siemens, Janitza และอุปกรณ์ SunSpec ส่วนใหญ่

## วิธีหาลำดับที่ถูกต้อง

1. **อ่านหัวข้อรูปแบบข้อมูลในคู่มือ** มองหา “word order”, “LSW first”, “MSW first”, “high word first” หรือ “big endian”
2. **อ่านค่าที่คุณรู้อยู่แล้ว** อ่านแรงดันที่ควรอยู่ราว 230 V เป็น float ในแต่ละลำดับ จะมีเพียงลำดับเดียวที่ให้ตัวเลขสมเหตุสมผล
3. **สังเกตตัวนับ** หากรีจิสเตอร์ต่ำของมิเตอร์พลังงานล้นไปยังส่วนที่เครื่องมือของคุณแสดงเป็นส่วนสูง ให้สลับเวิร์ด
4. **ตรวจค่า 64 บิตแยกต่างหาก** อุปกรณ์บางรุ่นเก็บค่า 32 บิตแบบเวิร์ดสูงก่อน และค่า 64 บิตในลำดับอื่น

## สตริง

ข้อความมักเก็บสองตัวอักษรต่อรีจิสเตอร์ โดยตัวอักษรแรกอยู่ในไบต์สูง อุปกรณ์บางรุ่นวางตัวอักษรแรกไว้ในไบต์ต่ำ ทำให้ “EM24” ถูกอ่านเป็น “ME42”

## แมป MBMap บันทึกเรื่องนี้อย่างไร

แมปกำหนด `byte_order` และ `word_order` ให้ทั้งอุปกรณ์ และรีจิสเตอร์ใดก็แทนที่ค่าเหล่านี้ได้ หน้าอุปกรณ์แสดงลำดับของทุกค่าที่มีหลายรีจิสเตอร์ด้วยรูปแบบข้างต้น (เช่น `float32 CDAB`) และการส่งออก Home Assistant แปลงเป็นตัวเลือก `swap:` ที่ถูกต้อง
