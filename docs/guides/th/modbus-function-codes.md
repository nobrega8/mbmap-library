# รหัสฟังก์ชันและพื้นที่รีจิสเตอร์ของ Modbus

ทุกคำขอ Modbus ระบุรหัสฟังก์ชัน รหัสนี้กำหนดทั้งการกระทำและพื้นที่ของอุปกรณ์ที่การกระทำนั้นมีผล

| รหัส | ชื่อ | พื้นที่ | ขนาด |
|---|---|---|---|
| 01 | Read Coils | คอยล์ (0x) | บิต อ่าน/เขียน |
| 02 | Read Discrete Inputs | อินพุตแบบดิสครีต (1x) | บิต อ่านอย่างเดียว |
| 03 | Read Holding Registers | โฮลดิงรีจิสเตอร์ (4x) | 16 บิต อ่าน/เขียน |
| 04 | Read Input Registers | อินพุตรีจิสเตอร์ (3x) | 16 บิต อ่านอย่างเดียว |
| 05 | Write Single Coil | คอยล์ | เขียน `0xFF00` เพื่อเปิด `0x0000` เพื่อปิด |
| 06 | Write Single Register | โฮลดิงรีจิสเตอร์ | หนึ่งรีจิสเตอร์ |
| 15 (0x0F) | Write Multiple Coils | คอยล์ | หลายบิต |
| 16 (0x10) | Write Multiple Registers | โฮลดิงรีจิสเตอร์ | หลายรีจิสเตอร์ |
| 17 (0x11) | Report Server ID | — | ข้อมูลระบุอุปกรณ์ รูปแบบกำหนดโดยอุปกรณ์ |
| 43 / 14 (0x2B/0x0E) | Read Device Identification | — | ผู้ผลิต รหัสผลิตภัณฑ์ รีวิชัน เป็นข้อความ |

## โฮลดิงหรืออินพุต

ตารางในคู่มือหรือคำนำหน้าที่อยู่จะบอกคุณ `3xxxx` อ่านด้วย 04 ส่วน `4xxxx` อ่านด้วย 03 อุปกรณ์บางรุ่นตอบทั้งสองฟังก์ชันด้วยข้อมูลเดียวกัน บางรุ่นปฏิเสธฟังก์ชันที่ผิดด้วยข้อยกเว้น 01 (illegal function) หากคู่มือไม่ระบุทั้งคำนำหน้าและฟังก์ชัน ให้ลอง 03 ก่อน

## การเขียน

- ค่า 32 บิตต้องเขียนสองรีจิสเตอร์ด้วยกันด้วย 16 การเขียนครึ่งละครั้งด้วย 06 อาจทำให้อุปกรณ์มีค่าที่ปนกัน หรือถูกปฏิเสธ
- อุปกรณ์บางรุ่นรับเฉพาะ 06 รุ่นอื่นรับเฉพาะ 16 รายการฟังก์ชันที่รองรับในคู่มือจะตัดสินเรื่องนี้
- คอยล์ที่เขียนด้วย 05 ต้องมี `0xFF00` หรือ `0x0000` เท่านั้น

## แมป MBMap บันทึกเรื่องนี้อย่างไร

แต่ละรีจิสเตอร์มี `area` (`coil`, `discrete`, `input`, `holding`) และ `access` (`R`, `W`, `RW`) เครื่องมือเลือกฟังก์ชันจากสองค่านี้ แมปยังอธิบายฟังก์ชันระบุตัวตน 17 และ 43 ได้ด้วย เพื่อให้เครื่องมือตรวจสอบได้ว่ากำลังคุยกับอุปกรณ์ใด
