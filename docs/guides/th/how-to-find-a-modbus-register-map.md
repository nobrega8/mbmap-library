# วิธีหาแมปรีจิสเตอร์ Modbus ของอุปกรณ์

แมปรีจิสเตอร์ (เรียกอีกอย่างว่าตาราง Modbus รายการจุด แมปหน่วยความจำ หรือโปรโตคอลการสื่อสาร) มักไม่อยู่ในเอกสารการติดตั้ง ที่ที่ควรมองหา:

1. **ค้นหาในไลบรารีนี้** ด้วยรุ่น รหัสรุ่น หรือชื่อเรียกอื่น ทุกแมปมีลิงก์ไปยังเอกสารที่ใช้เขียน
2. **พื้นที่ดาวน์โหลดของผู้ผลิต** ค้นหา “communication protocol”, “Modbus protocol”, “Modbus register map”, “Modbus table” หรือ “point map” พร้อมชื่อรุ่น มักเป็น PDF แยกจากคู่มือผู้ใช้
3. **คู่มือผู้ใช้ฉบับเต็ม** คู่มือหลายเล่มมีตารางอยู่ในบทใกล้ท้ายเล่ม (“Communication”, “Modbus”, “Appendix B”)
4. **ซอฟต์แวร์ตั้งค่า** ผู้ผลิตบางรายแนบแมปไว้ในซอฟต์แวร์ หรือเป็นไฟล์ Excel ที่มาด้วยกัน
5. **เอกสารของตระกูลผลิตภัณฑ์** รุ่นหนึ่งมักใช้แมปร่วมกับตระกูลของมัน (“EM24 DIN”, “PM5000 series”) ตรวจสอบว่าคู่มือของตระกูลครอบคลุมรุ่นย่อยของคุณ
6. **สอบถามฝ่ายสนับสนุนของผู้ผลิต** แมปบางแมปส่งให้เมื่อร้องขอเท่านั้น บางครั้งภายใต้ NDA ตรวจสอบว่าคุณแบ่งปันได้หรือไม่ก่อนเผยแพร่แมปที่ทำจากแมปนั้น
7. **การผสานรวมของโปรเจกต์อื่น** คอนฟิกของ Home Assistant, openHAB, Node-RED และ EVCC มักมีรายการรีจิสเตอร์ที่ใช้งานได้ แต่ให้ตรวจสอบกับคู่มือ

## สิ่งที่ควรอ่านในนั้น

- **หลักเกณฑ์การกำหนดที่อยู่** (ที่อยู่บนสาย นับจาก 1 หรือ Modicon) ดู[ที่อยู่](modbus-address-off-by-one)
- **ชนิดข้อมูล** **ลำดับเวิร์ด** และ**สเกล**ของแต่ละค่า ดู[ลำดับไบต์และเวิร์ด](byte-and-word-order)และ[การปรับสเกล](scaling-and-units)
- **รหัสฟังก์ชันที่รองรับ** และจำนวนรีจิสเตอร์สูงสุดต่อคำขอ
- **การตั้งค่าซีเรียลเริ่มต้น**และ unit ID
