# การเขียนลงอุปกรณ์ Modbus ปลอดภัยหรือไม่

การอ่านรีจิสเตอร์ไม่มีอันตราย การเขียนทำให้อุปกรณ์เปลี่ยนไป บางครั้งในทางที่ยากจะย้อนกลับ

## สิ่งที่อาจผิดพลาด

- **รีจิสเตอร์ผิดตัว** [ที่อยู่ที่คลาดไปหนึ่ง](modbus-address-off-by-one)จะเขียนค่าของคุณลงในค่าตั้งข้างเคียง เช่น อัตราส่วน CT ขีดจำกัดการป้องกัน หรืออัตราบอด
- **การตั้งค่าการสื่อสาร** การเขียน unit ID อัตราบอด หรือพาริตี ทำให้คุณเชื่อมต่อไม่ได้จนกว่าจะเชื่อมต่อใหม่ด้วยค่าใหม่
- **หน่วยความจำสึกหรอ** อุปกรณ์หลายรุ่นบันทึกค่าตั้งลง flash หรือ EEPROM ซึ่งเขียนได้จำนวนครั้งจำกัด การเขียนค่าเซ็ตพอยต์ทุกวินาทีอาจทำให้สึกหรอภายในไม่กี่เดือน อุปกรณ์บางรุ่นมีที่อยู่ที่ใช้ RAM อย่างเดียวสำหรับการเขียนบ่อย ๆ
- **คำสั่งมีผลทันที** การรัน/หยุด การเปิด/ปิดเบรกเกอร์ การรีเซ็ตตัวนับพลังงาน และการคืนค่าโรงงานเกิดขึ้นทันทีที่เขียน โดยไม่มีการยืนยัน
- **ค่าที่เขียนไม่ครบ** การเขียนสองรีจิสเตอร์ของค่า 32 บิตในคำขอแยกกันอาจทำให้เกิดค่าที่ปนกันชั่วขณะ หรือถูกปฏิเสธ

## ก่อนเขียน

1. ตรวจสอบแมปกับเอกสารของผู้ผลิต และเลือกแมปที่มีสถานะ *ตรวจสอบแล้ว* หรือ *ทางการ*
2. อ่านรีจิสเตอร์ก่อน และยืนยันว่ามีค่าตามที่คุณคาดหวัง
3. ตรวจช่วงที่อนุญาต อุปกรณ์หลายรุ่นจำกัดหรือปฏิเสธค่านอกช่วง
4. เขียนค่าที่มีหลายรีจิสเตอร์ในคำขอเดียว (ฟังก์ชัน 16)
5. รู้ว่าจะคืนค่าเดิมได้อย่างไร
6. กับอุปกรณ์ที่ควบคุมกำลังไฟหรือเครื่องจักร ให้ทดสอบโดยแยกอุปกรณ์ออก

## แมป MBMap ช่วยได้อย่างไร

รีจิสเตอร์มี `access` (`R`, `W`, `RW`) และรีจิสเตอร์ที่เขียนได้อาจมี `write_min` และ `write_max` แต่ละแมปมีสถานะที่บอกว่าผ่านการทดสอบกับอุปกรณ์ นำมาจากเอกสารของผู้ผลิต หรือยังไม่ได้ตรวจสอบ เครื่องมือควรเตือนก่อนเขียนลงอุปกรณ์ที่รุ่นไม่ตรงกับแมป
