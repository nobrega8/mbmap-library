# Коды исключений Modbus: что сообщает устройство

Когда устройство Modbus понимает запрос, но не может его выполнить, оно отвечает исключением: кодом функции со взведённым старшим битом (`0x83` для неудачного чтения регистров хранения) и однобайтовым кодом.

| Код | Название | Обычная причина | Что попробовать |
|---|---|---|---|
| 01 | Illegal function | Устройство не поддерживает этот код функции: чтение входных регистров (04) у устройства только с регистрами хранения или запись функцией 16 в устройство, принимающее только 06 | Используйте код функции, который руководство указывает для этой таблицы |
| 02 | Illegal data address | Адреса не существует или запрошенный блок попадает в пропуск | Проверьте [смещение адреса](modbus-address-off-by-one); читайте меньше регистров за раз |
| 03 | Illegal data value | Слишком большое количество (больше 125 регистров) или записываемое значение вне диапазона | Читайте блоки поменьше; перед записью проверьте допустимый диапазон |
| 04 | Server device failure | Устройство дало сбой при выполнении; некоторые устройства используют его для любой отклонённой записи или для чтения блока, который они не допускают | Читайте по одному регистру; проверьте состояние устройства |
| 05 | Acknowledge | Принято, но потребуется время (программирование, сохранение) | Подождите, затем опрашивайте |
| 06 | Server device busy | Устройство занято | Повторите позже |
| 0A | Gateway path unavailable | Шлюз не смог достучаться до устройства за ним | Проверьте последовательную сторону шлюза и его маршрутизацию |
| 0B | Gateway target failed to respond | Шлюз переслал запрос, но устройство не ответило | Проверьте unit ID, скорость и проводку за шлюзом |

## Полное отсутствие ответа — это не исключение

Устройство, получившее кадр с неверным CRC, неверным unit ID или ошибкой чётности, молчит: вы получаете тайм-аут, а не исключение. См. [тайм-ауты](modbus-timeout-no-response).

## Блоки, охватывающие пропуски

Многие устройства отклоняют чтение, захватывающее любой неиспользуемый адрес, даже если все нужные вам регистры существуют. Если чтение 20 регистров завершается кодом 02, а по одному они читаются, разбейте запрос по пропускам. Карты могут указывать, сколько регистров устройство принимает за запрос (`max_read_registers`).
