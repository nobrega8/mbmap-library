# Коды функций Modbus и области регистров

Каждый запрос Modbus называет код функции. Он определяет и действие, и область устройства, с которой оно выполняется.

| Код | Название | Область | Размер |
|---|---|---|---|
| 01 | Read Coils | coil (0x) | биты, чтение/запись |
| 02 | Read Discrete Inputs | дискретные входы (1x) | биты, только чтение |
| 03 | Read Holding Registers | регистры хранения (4x) | 16 бит, чтение/запись |
| 04 | Read Input Registers | входные регистры (3x) | 16 бит, только чтение |
| 05 | Write Single Coil | coil | запишите `0xFF00` для включения, `0x0000` для выключения |
| 06 | Write Single Register | регистры хранения | один регистр |
| 15 (0x0F) | Write Multiple Coils | coil | несколько бит |
| 16 (0x10) | Write Multiple Registers | регистры хранения | несколько регистров |
| 17 (0x11) | Report Server ID | — | идентификатор устройства, формат задаёт устройство |
| 43 / 14 (0x2B/0x0E) | Read Device Identification | — | производитель, код продукта, версия в виде текста |

## Хранения или входной?

Таблица в руководстве или префикс адреса подскажут: `3xxxx` читается функцией 04, `4xxxx` — функцией 03. Некоторые устройства отвечают на обе функции одними и теми же данными; другие отклоняют неверную исключением 01 (illegal function). Если руководство не указывает ни префикса, ни функции, сначала попробуйте 03.

## Запись

- 32-битное значение требует записи двух регистров вместе функцией 16; запись его половин по одной функцией 06 может оставить устройство со смешанным значением или быть отклонена.
- Некоторые устройства принимают только 06, другие — только 16. Вопрос решает список поддерживаемых функций в руководстве.
- Coil, записываемые функцией 05, должны нести ровно `0xFF00` или `0x0000`.

## Как это записано в картах MBMap

У каждого регистра есть `area` (`coil`, `discrete`, `input`, `holding`) и `access` (`R`, `W`, `RW`); инструмент выбирает функцию по ним. Карты могут также описывать функции идентификации 17 и 43, чтобы инструмент мог проверить, с каким устройством он говорит.
