# Unit ID Modbus (slave ID): какое устройство отвечает

Каждый запрос Modbus несёт однобайтовый unit ID, который также называют slave ID, адресом ведомого или адресом устройства.

## По RS-485 (Modbus RTU)

- У каждого устройства на шине свой адрес от 1 до 247, который задают на дисплее, DIP-переключателями или в программе конфигурации.
- Адрес 0 — широковещательный: каждое устройство выполняет запись, и никто не отвечает. На чтение по адресу 0 ответа нет.
- Устройство с другим адресом полностью игнорирует ваш запрос, поэтому неверный unit ID выглядит как неработающее устройство: вы получаете [тайм-аут](modbus-timeout-no-response), а не ошибку.

## По Modbus TCP

- Устройство, к которому обращаются напрямую по IP, обычно игнорирует unit ID или ждёт 1. Некоторые ждут 0 или 255, а немногие отвергают всё, кроме настроенного значения.
- За шлюзом TCP–RTU unit ID выбирает последовательное устройство: он должен совпадать с адресом этого устройства в RS-485. Сам шлюз часто отвечает по 0, 255 или настроенному ID.
- Некоторые устройства с несколькими внутренними частями (инвертор со счётчиком и батареей) отвечают на разные unit ID для каждой части.

## Как найти неизвестный адрес

- Прочитайте его на дисплее или наклейке устройства.
- Просканируйте: отправьте чтение распространённого регистра на каждый адрес от 1 до 247 на скорости устройства и отметьте, кто ответит. Делайте это, подключив только это устройство.
- Сбросьте к заводским настройкам; адрес по умолчанию указан в руководстве (часто 1).

## Как это записано в картах MBMap

Карта указывает `unit_id` устройства по умолчанию (а также последовательные настройки и порт TCP). Значение по умолчанию — лишь отправная точка: при установке устройства обычно перенастраивают.
