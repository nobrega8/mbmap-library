# Modbus RTU、Modbus TCP 和 RS-485

这三个名称经常被混淆。

| | Modbus RTU | Modbus TCP |
|---|---|---|
| 介质 | 串行线路，几乎总是 RS-485（有时是 RS-232） | 以太网或 Wi-Fi |
| 寻址 | 总线上的单元 ID 1–247 | IP 地址和端口（502），外加单元 ID |
| 错误校验 | 每个帧中有 CRC-16 | 依靠 TCP 自身的校验；没有 CRC |
| 帧结构 | 帧之间有 3.5 个字符的静默 | 带长度的 7 字节报文头（MBAP） |
| 每条链路的设备数 | 每段最多 32 个单位负载（使用低负载收发器可更多），一个主站 | 每台设备可有多个客户端，受设备限制 |
| 典型速度 | 9600–115200 波特 | 10/100 Mbit/s，受设备限制 |

**RS-485** 只是电气层：两根线、差分信号、一条总线。Modbus RTU 运行在其上，其他协议也一样（BACnet MS/TP、DMX、通过 RS-485 适配器的 M-Bus）。

**Modbus ASCII** 把相同的请求以可读的十六进制文本发送；如今已很少见。

## 寄存器相同

无论传输方式如何，寄存器映射表都一样：同时支持两种方式的设备，使用相同的地址、类型和比例应答。变化的只是连接设备的方式：RTU 使用串口设置和单元 ID，TCP 使用 IP 地址和端口。

## 网关

Modbus TCP 转 RTU 网关让以太网工具可以访问串口设备。TCP 请求中的单元 ID 用来选择串口侧的设备。网关有自己的超时；如果网关后面的设备没有应答，请先检查网关上的串口设置。

## MBMap 映射表如何记录

映射表说明设备提供哪些传输方式（`protocol`：`rtu`、`tcp` 或两者），以及它们的默认值（`baudrate`、`parity`、`databits`、`stopbits`、`port`、`unit_id`）。
