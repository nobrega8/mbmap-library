# Modbus 功能码和寄存器区域

每个 Modbus 请求都带有一个功能码。它既决定了操作，也决定了作用于设备的哪个区域。

| 代码 | 名称 | 区域 | 大小 |
|---|---|---|---|
| 01 | 读线圈 | 线圈（0x） | 位，可读写 |
| 02 | 读离散输入 | 离散输入（1x） | 位，只读 |
| 03 | 读保持寄存器 | 保持寄存器（4x） | 16 位，可读写 |
| 04 | 读输入寄存器 | 输入寄存器（3x） | 16 位，只读 |
| 05 | 写单个线圈 | 线圈 | 写 `0xFF00` 表示开，`0x0000` 表示关 |
| 06 | 写单个寄存器 | 保持寄存器 | 一个寄存器 |
| 15（0x0F） | 写多个线圈 | 线圈 | 多个位 |
| 16（0x10） | 写多个寄存器 | 保持寄存器 | 多个寄存器 |
| 17（0x11） | 报告服务器 ID | — | 设备标识，格式由设备决定 |
| 43 / 14（0x2B/0x0E） | 读设备标识 | — | 供应商、产品代码、版本，文本形式 |

## 保持寄存器还是输入寄存器？

手册中的表格或其地址前缀会告诉你：`3xxxx` 用 04 读取，`4xxxx` 用 03 读取。有些设备对两种功能返回相同的数据；另一些设备会对错误的功能以异常 01（非法功能）拒绝。如果手册既没有给出前缀也没有给出功能，请先试 03。

## 写入

- 32 位数值需要用 16 一次写入两个寄存器；用 06 逐个写入两半，可能让设备得到混合的值，或者被拒绝。
- 有些设备只接受 06，有些只接受 16。手册中支持的功能列表可以确定这一点。
- 用 05 写入的线圈必须恰好是 `0xFF00` 或 `0x0000`。

## MBMap 映射表如何记录

每个寄存器都有 `area`（`coil`、`discrete`、`input`、`holding`）和 `access`（`R`、`W`、`RW`）；工具据此选择功能码。映射表还可以描述标识功能 17 和 43，让工具能够核对它正在与哪台设备通信。
