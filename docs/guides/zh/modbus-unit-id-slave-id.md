# Modbus 单元 ID（从站 ID）：由哪台设备应答

每个 Modbus 请求都带有一个字节的单元 ID，也称为从站 ID、从站地址或设备地址。

## 在 RS-485（Modbus RTU）上

- 总线上的每台设备都有自己的地址，范围 1 到 247，通过显示屏、拨码开关或配置软件设置。
- 地址 0 是广播：每台设备都会执行写入，没有设备应答。发给 0 的读取不会有回复。
- 设置为其他地址的设备会完全忽略你的请求，所以错误的单元 ID 看起来就像设备已死：你得到的是[超时](modbus-timeout-no-response)，而不是错误。

## 在 Modbus TCP 上

- 通过 IP 直接访问的设备通常会忽略单元 ID，或者期望它为 1。有些期望 0 或 255，还有少数设备只接受其配置的值。
- 在 TCP 转 RTU 网关后面，单元 ID 用来选择串口设备：它必须与该设备的 RS-485 地址一致。网关本身通常使用 0、255 或配置的 ID 应答。
- 有些包含多个内部部分的设备（带电表和电池的逆变器）会对每个部分使用不同的单元 ID 应答。

## 查找未知的地址

- 从设备的显示屏或标签上读取。
- 扫描：以设备的波特率，对 1 到 247 的每个地址发送一次常见寄存器的读取，记录哪个地址有应答。扫描时只连接这台设备。
- 恢复出厂设置；手册会给出默认值（通常为 1）。
