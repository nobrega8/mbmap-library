# 字节序和字序：32 位数值出错时怎么办

电压读出 1.7 × 10³⁸，电能计数器每次跳 65 536，或者温度是一个很小的负数。寄存器没有读错；问题在于 32 位数值的两个寄存器的组合顺序。

## 一个寄存器很简单，两个就不一定

Modbus 寄存器是 16 位，先发送最高有效字节。标准没有规定超过一个寄存器的数值如何传输，因此每个制造商都自行决定如何把 32 位整数或浮点数拆到两个寄存器中（64 位数值则拆到四个寄存器中）。

这四种顺序通常以数值的字节命名，`A` 为最高有效字节：

| 名称 | 寄存器 1 | 寄存器 2 | 其他叫法 |
|---|---|---|---|
| `ABCD` | A B | C D | 大端序，高字在前 |
| `CDAB` | C D | A B | 字交换，低字在前，LSW 在前 |
| `BADC` | B A | D C | 字节交换 |
| `DCBA` | D C | B A | 小端序，字节和字都交换 |

`ABCD` 和 `CDAB` 涵盖了几乎所有设备。`CDAB` 常见于施耐德、佳乐（Carlo Gavazzi）和许多国产电表；`ABCD` 常见于西门子、Janitza 和大多数 SunSpec 设备。

## 如何找到正确的顺序

1. **阅读手册中的数据格式部分。** 查找“word order”“LSW first”“MSW first”“high word first”或“big endian”。
2. **读取一个已知的值。** 读取一个应该在 230 V 左右的电压，按每种顺序当作浮点数解析。只有一种会得到合理的数字。
3. **观察计数器。** 如果电能计数器的低位寄存器进位到了工具显示的高位部分，请交换两个字。
4. **单独检查 64 位数值。** 有些设备以高字在前存储 32 位数值，而 64 位数值采用另一种顺序。

## 字符串

文本通常每个寄存器存两个字符，第一个字符在高字节。少数设备把第一个字符放在低字节，结果“EM24”会被读成“ME42”。

## MBMap 映射表如何记录

映射表为整台设备设置 `byte_order` 和 `word_order`，任何寄存器都可以覆盖它们。设备页面以上述记法显示每个多寄存器数值的顺序（例如 `float32 CDAB`），Home Assistant 导出会把它转换成正确的 `swap:` 选项。
