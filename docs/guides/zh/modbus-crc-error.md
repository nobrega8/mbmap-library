# RS-485 上的 Modbus CRC 错误

CRC 错误表示收到了一个帧，但其校验和不匹配：字节在传输途中被改变或丢失。与地址错误不同，它指向的是物理链路或时序问题。

## 常见原因

- **噪声。** 无屏蔽电缆紧挨着动力电缆或变频器敷设。请使用屏蔽双绞线，屏蔽层只在一端接地。
- **终端电阻缺失或多余。** 总线两端各一个 120 Ω 电阻；中间不要有。
- **没有偏置。** 空闲的总线如果没有偏置电阻，电平会浮动，帧的前几个字节可能被误读。许多转换器和主站都有偏置选项。
- **分支和星形接线。** RS-485 要求设备之间是一条线，而不是分支。
- **波特率略有偏差**，出现在廉价转换器上或速率较高时。请尝试较低的波特率。
- **帧粘在一起。** 如果主站在总线静默 3.5 个字符时间之前就发出下一个请求，设备看到的是一个又长又残缺的帧。请增大请求之间的延迟。
- **两个主站**，或者有设备与另一台设备使用相同的地址应答。

## 排查步骤

1. 降低波特率，看错误是否消失。
2. 只接一台设备，并用短电缆测试。如果正常，问题出在总线，而不是设备。
3. 在断电状态下检查终端电阻：两端终端电阻都接上时，A 和 B 之间的电阻应约为 60 Ω。
4. 如果主站或转换器提供偏置，请启用。
5. 增大轮询间隔和超时时间。

在较长的工业总线上偶尔出现 CRC 错误是正常的；工具应当重试。如果大多数帧都出错，则不正常。
