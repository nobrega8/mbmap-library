# 向 Modbus 设备写入安全吗？

读取寄存器没有危害。写入寄存器会改变设备，有时难以撤销。

## 可能出什么问题

- **寄存器写错。** [差一位的地址](modbus-address-off-by-one)会把你的值写入相邻的设置：CT 变比、保护限值、波特率。
- **通信设置。** 写入单元 ID、波特率或校验位后，你会失去连接，直到用新的值重新连接。
- **存储器磨损。** 许多设备把设置保存在闪存或 EEPROM 中，写入次数有限。每秒写一次设定值，可能在几个月内将其写坏。有些设备为频繁写入提供仅写 RAM 的地址。
- **命令立即生效。** 运行/停止、断路器分合、电能计数器清零和恢复出厂设置在写入的瞬间执行，没有确认。
- **只写了一半的值。** 把 32 位数值的两个寄存器分成不同请求写入，可能让设备在一瞬间得到混合的值，或者被拒绝。

## 写入之前

1. 对照制造商文档检查映射表，优先选择标记为*已验证*或*官方*的映射表。
2. 先读取该寄存器，确认其内容符合预期。
3. 检查允许的范围；许多设备会对超出范围的值进行限幅或拒绝。
4. 多寄存器的值在一个请求中写入（功能码 16）。
5. 知道如何恢复旧值。
6. 对于控制电源或机械的设备，请在隔离状态下测试。

## MBMap 映射表如何提供帮助

寄存器有 `access`（`R`、`W`、`RW`），可写的寄存器还可以带有 `write_min` 和 `write_max`。每个映射表都有一个状态，说明它是否在设备上测试过、取自制造商文档，还是尚未核实。向型号与映射表不符的设备写入之前，工具应当给出警告。
