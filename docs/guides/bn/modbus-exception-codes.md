# Modbus এক্সসেপশন কোড: ডিভাইস আপনাকে কী বলছে

কোনো Modbus ডিভাইস অনুরোধ বুঝতে পারলেও তা সম্পন্ন করতে না পারলে সে একটি এক্সসেপশন দিয়ে উত্তর দেয়: ফাংশন কোড যার সর্বোচ্চ বিট সেট করা (হোল্ডিং রেজিস্টার পড়া ব্যর্থ হলে `0x83`) এবং এক বাইটের একটি কোড।

| কোড | নাম | সাধারণ কারণ | কী চেষ্টা করবেন |
|---|---|---|---|
| 01 | Illegal function | ডিভাইস এই ফাংশন কোড সমর্থন করে না: শুধু হোল্ডিং রেজিস্টারওয়ালা ডিভাইসে ইনপুট রেজিস্টার (04) পড়া, বা শুধু 06 নেয় এমন ডিভাইসে 16 দিয়ে লেখা | ম্যানুয়াল ওই সারণির জন্য যে ফাংশন কোড বলে সেটি ব্যবহার করুন |
| 02 | Illegal data address | ঠিকানাটি নেই, বা চাওয়া ব্লক কোনো ফাঁকে গিয়ে পড়েছে | [ঠিকানার অফসেট](modbus-address-off-by-one) যাচাই করুন; একবারে কম রেজিস্টার পড়ুন |
| 03 | Illegal data value | পরিমাণ খুব বেশি (125-এর বেশি রেজিস্টার) বা লেখা মান সীমার বাইরে | ছোট ব্লক পড়ুন; লেখার আগে অনুমোদিত সীমা যাচাই করুন |
| 04 | Server device failure | কাজটি করার সময় ডিভাইস ব্যর্থ হয়েছে; কিছু ডিভাইস প্রত্যাখ্যাত যেকোনো লেখা বা অনুমতি নেই এমন ব্লক পড়ার জন্য এটি ব্যবহার করে | একবারে একটি রেজিস্টার পড়ুন; ডিভাইসের অবস্থা যাচাই করুন |
| 05 | Acknowledge | গৃহীত হয়েছে, কিন্তু কিছু সময় লাগবে (প্রোগ্রামিং, সংরক্ষণ) | অপেক্ষা করুন, তারপর পোল করুন |
| 06 | Server device busy | ডিভাইস ব্যস্ত | পরে আবার চেষ্টা করুন |
| 0A | Gateway path unavailable | গেটওয়ে তার পেছনের ডিভাইসে পৌঁছাতে পারেনি | গেটওয়ের সিরিয়াল দিক ও তার রাউটিং যাচাই করুন |
| 0B | Gateway target failed to respond | গেটওয়ে অনুরোধটি এগিয়ে দিয়েছে কিন্তু ডিভাইস উত্তর দেয়নি | গেটওয়ের পেছনে unit ID, baud রেট ও ওয়্যারিং যাচাই করুন |

## কোনো উত্তর না আসা এক্সসেপশন নয়

যে ডিভাইস ভুল CRC, ভুল unit ID বা প্যারিটি ত্রুটিসহ ফ্রেম পায়, সে চুপ থাকে: আপনি টাইমআউট পান, এক্সসেপশন নয়। [টাইমআউট](modbus-timeout-no-response) দেখুন।

## ফাঁক পেরিয়ে যাওয়া ব্লক

অনেক ডিভাইস যেকোনো অব্যবহৃত ঠিকানা ছুঁয়ে যায় এমন পড়া প্রত্যাখ্যান করে, আপনার দরকারি প্রতিটি রেজিস্টার থাকলেও। 20টি রেজিস্টার পড়া 02 দিয়ে ব্যর্থ হলে কিন্তু একটি একটি করে পড়া কাজ করলে, অনুরোধটি ফাঁকগুলোতে ভাগ করুন। ম্যাপ জানাতে পারে ডিভাইস প্রতি অনুরোধে কতগুলো রেজিস্টার নেয় (`max_read_registers`)।
