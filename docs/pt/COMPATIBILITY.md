# Compatibilidade

Ferramentas que leem ficheiros `.mbmap` e que partes do formato ([SPEC.md](SPEC.md)) cada uma suporta.

## Ferramentas

| Ferramenta | O que é | O que faz com um mapa |
|---|---|---|
| <img src="https://raw.githubusercontent.com/nobrega8/modbench/main/assets/icon.svg" width="20" height="20" alt="" align="top"> [Modbench](https://github.com/nobrega8/modbench) | Cliente Modbus TCP/UDP/RTU/ASCII para Windows, Linux e macOS, com linha de comandos (`modbench-cli`) e um servidor MCP | Abre um mapa e lê (e escreve) o dispositivo pelo nome do registo; navega e descarrega esta biblioteca; executa um dispositivo simulado à imagem de um mapa. Na linha de comandos: `validate` e `convert` mapas, e `map` lê de um dispositivo todos os registos de um mapa; as ferramentas MCP `read_map` e `validate_map` fazem o mesmo para um assistente de IA |
| <img src="assets/tools/scanbus-br.png" width="20" height="20" alt="" align="top"> [ScanBus-BR](https://github.com/ortegahernandes/ScanBus-BR-Simulator-Modbus) | Mestre Modbus RTU/TCP gratuito, simulador de escravo e sniffer RTU para Windows e Linux (a partir da versão 5.2.0) | Pesquisa esta biblioteca e mostra os registos de um dispositivo (nome, função, endereço); importa os nomes dos registos como alias e preenche a função, o endereço inicial, o tipo e a ordem de bytes do primeiro registo, mais o ID da unidade, o baud rate, a paridade e os bits de paragem do mapa. A sua tabela principal lê blocos contíguos (um endereço inicial e uma contagem), não registos isolados por nome; clicar num registo abre-o numa janela à parte. Desde a 5.3.0, uma janela de registos (alfa) lista todos os registos do dispositivo escolhido; a 5.3.1 acrescenta um filtro e seletores de grupo de funções e de firmware. Mostra o estado de cada mapa e guarda um mapa como CSV (só os registos), TXT ou RTF (com descrições e notas) |
| <img src="assets/tools/mtui.png" width="20" height="20" alt="" align="top"> [MTUI](https://github.com/inowattio/MTUI) | Cliente Modbus TCP/RTU para o terminal, orientado pelo teclado, para Windows, Linux e macOS, com uma demonstração web (a partir da versão 1.6.0) | Importa um mapa colado: cada registo é fixado e identificado com o seu nome e unidade, e recebe uma regra que descodifica o seu tipo, ordem de bytes e de palavras, escala, deslocamento e tabela de tradução. Os registos que não consegue descodificar (cadeias, campos de vários bits) ficam só com a etiqueta |
| <img src="assets/tools/modbus-tools.png" width="20" height="20" alt="" align="top"> [Modbus Tools](https://github.com/serhmarch/ModbusTools) | Cliente Modbus (ModbusClient) e simulador de servidor (ModbusServer) para Windows e Linux, com TCP, UDP, RTU e ASCII (ainda não está numa versão publicada: o suporte está integrado no ramo `v0.5dev`) | **Data › Import Data View…** e **Import Items…** aceitam um ficheiro `.mbmap.json`: cada registo passa a um item de vista de dados (endereço, formato, ordem de bytes e de palavras, e um comentário com o nome, a unidade, a escala e o deslocamento), e a vista tem o nome do mapa. Os campos de bits e os bits `bool` de um registo tornam-se um item `Bin16` por registo, com o comentário a nomear cada bit. A exportação não muda |
| <img src="assets/tools/open-modscan.png" width="20" height="20" alt="" align="top"> [Open ModScan](https://github.com/sanny32/OpenModScan) | Mestre (cliente) Modbus gratuito para Windows e Linux (integrado no ramo `dev`, ainda não numa versão publicada: a 1.16.2 não o tem) | File › Open aceita um ficheiro `.mbmap.json`: os registos são agrupados em janelas por área, modo de apresentação e ordem de bytes (lacunas até 10 endereços, dentro dos limites de leitura), cada uma configurada com o tipo de ponto, o endereço inicial, o comprimento, o ID do dispositivo, a base dos endereços e o modo de apresentação, e os nomes dos registos (com unidade e escala) como descrições dos endereços. Um mapa com mais de 8 janelas abre uma lista para escolher. File › Device Map Library descarrega o índice desta biblioteca, lista os mapas com um filtro e abre o escolhido |

## Acrescentar uma ferramenta

Está a construir uma ferramenta que lê `.mbmap`? Siga o [SPEC.md](SPEC.md) e confira-a com os ficheiros de exemplo em [`tests/`](tests/): cada um lista os diagnósticos que um leitor deve comunicar. Depois abra um pull request que acrescente a sua ferramenta a esta página, com o que suporta. O suporte parcial é aceitável: diga que partes lê e quais ignora.
